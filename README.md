
# Udemy Kurslarım – React Projesi

Bu proje, React kullanılarak geliştirilmiş basit ve modern bir kurs listeleme uygulamasıdır.  
Amaç; component yapısını ve props kullanımını öğrenmektir.

## Kullanılan Teknolojiler
- React
- JavaScript
- HTML
- CSS

## Proje Özellikleri
- Kurslar kart yapısı ile listelenir
- Her kurs için görsel, başlık, açıklama ve fiyat gösterilir
- Component tabanlı yapı kullanılmıştır
